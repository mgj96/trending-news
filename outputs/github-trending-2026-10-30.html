상용 LLM의 안전 가이드라인과 필터링 시스템을 우회하여 제한된 답변을 끌어내는 최신 탈옥(Jailbreak) 프롬프트들을 체계적으로 정리한 프로젝트입니다. 텍스트 기반의 특수 프롬프트와 시나리오 기법을 통해 모델의 RLHF 설정을 무력화하는 방식을 공유하며, 보안 전문가들이 AI 모델의 취약점을 점검하는 레드팀(Red Teaming) 활동에 주로 활용됩니다. 실무에서는 자체 구축한 AI 서비스의 보안성을 테스트하는 벤치마크 데이터로 사용하거나, 해당 패턴을 역이용해 부적절한 입력을 차단하는 가드레일(Guardrail) 시스템 고도화에 응용할 수 있습니다. 해당 저장소를 포크하여 자동화된 LLM 취약점 스캐닝 도구나 실시간 프롬프트 인젝션 탐지 API 서버로 확장하는 아이디어를 추천합니다.

본 리포트는 GitHub Actions와 AI API를 통해 자동 생성되었습니다.
