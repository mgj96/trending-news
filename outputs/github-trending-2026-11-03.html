SSD의 빠른 읽기 속도를 활용해 수십 GB급 모델을 저사양 PC에서도 실행하며, 외부 라이브러리 의존성이 전혀 없는 퓨어 C 구현으로 최상의 이식성을 제공합니다. 고성능 GPU가 없는 엣지 디바이스나 구형 랩탑에서 최신 오픈소스 모델을 로컬로 구동하려는 수요를 정확히 공략했습니다. 해당 코드를 포크하여 특정 하드웨어 가속기(NPU) 최적화나 모바일 환경 전용 추론 라이브러리로의 확장이 용이합니다.

본 리포트는 GitHub Actions와 AI API를 통해 자동 생성되었습니다.
