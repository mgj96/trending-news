📖 상세
LLM은 훈련 데이터의 시차로 인해 Fetch API 대신 구식 라이브러리를 제안하는 등 최신 웹 표준과 동떨어진 결과물을 내놓는 경우가 빈번합니다. 이 프로젝트는 구글 크롬 팀이 직접 정제한 최신 웹 성능 지표와 API 사용법을 AI 에이전트가 즉각 소화할 수 있는 마크다운 기반 데이터셋으로 제공하여 이 문제를 해결합니다. 실무에서는 Cursor나 Copilot의 커스텀 룰(.cursorrules) 설정에 이 데이터를 주입하여 팀 전체의 코드 품질을 최신 사양으로 강제하고 유지보수 비용을 줄일 수 있습니다. 해당 레포를 포크하여 사내 보안 규정이나 특정 프레임워크 전용 스타일 가이드를 결합한 '엔터프라이즈 특화 AI 코딩 컨텍스트' 구축 도구로 활용하기에 용이합니다.
