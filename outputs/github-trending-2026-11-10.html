📖 상세
이 프로젝트는 Anthropic의 MCP(Model Context Protocol)를 통해 Home Assistant의 엔티티와 서비스를 LLM 도구로 노출하여 AI 에이전트가 직접 스마트홈을 관리하게 합니다. 사용자는 복잡한 코딩 대신 "거실 온도가 26도 이상이면 에어컨을 켜고 조명을 낮춰줘"와 같은 자연어 명령으로 실시간 기기 제어 및 자동화 로직을 즉시 실행할 수 있습니다. 실무적으로는 Claude 데스크톱 앱과 연동하여 통합 홈 제어 인터페이스로 활용 가능하며, 포크 시 로컬 LLM(Ollama) 기반의 프라이버시 강화형 스마트홈 비서나 에너지 최적화 전용 AI 에이전트로 확장하기 좋습니다.

본 리포트는 GitHub Actions와 AI API를 통해 자동 생성되었습니다.
