AiSOC은 산재된 보안 경보를 MITRE ATT&CK 프레임워크에 맞춰 통합하고, LLM 에이전트가 위협을 분석하는 오픈소스 보안 관제 플랫폼입니다. 로컬 LLM을 활용해 외부 API 노출 없이 민감한 보안 데이터를 분석하며, 에이전트의 모든 판단 근거를 리플레이 가능한 원장 형태로 남겨 AI의 오탐 여부를 명확히 검증할 수 있습니다. 특히 MCP(Model Context Protocol) 서버를 지원하여 Cursor나 Claude 데스크톱 앱에서 보안 위협 정보를 즉시 컨텍스트로 활용할 수 있는 점이 실무적입니다. 이 프로젝트를 포크하여 사내 보안 장비(EDR, SIEM) API와 연동하는 실시간 대응 파이프라인을 구축하거나, 특정 산업군에 특화된 보안 컴플라이언스 준수 여부 자동 검증 툴로 확장하기 좋습니다.

본 리포트는 GitHub Actions와 AI API를 통해 자동 생성되었습니다.
