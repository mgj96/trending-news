이 프로젝트는 LLM이 보안 취약점을 잘못 식별하는 할루시네이션 문제를 해결하기 위해, 다단계 독립 검증 프로세스를 거쳐 기계가 즉시 읽을 수 있는 보안 리포트를 생성합니다. 보안 전문가가 수동으로 수행하던 취약점 탐색과 검증 단계를 에이전트 스킬로 구현하여, 소스 코드 분석부터 실질적인 악용 가능성 확인까지 자동화된 워크플로우를 제공합니다. 실무에서는 GitHub Actions와 같은 CI/CD 파이프라인에 통합해 코드 배포 전 보안 결함을 조기에 발견하고, 표준화된 JSON 결과를 바탕으로 대시보드나 알림 시스템에 즉시 반영할 수 있습니다. 만약 포크를 한다면 특정 프레임워크 전용 보안 룰셋을 추가하거나, 생성된 취약점 리포트를 바탕으로 수정 코드를 제안하는 패치 에이전트 기능을 확장해볼 수 있습니다.

본 리포트는 GitHub Actions와 AI API를 통해 자동 생성되었습니다.
